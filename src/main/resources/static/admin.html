아이디 / 비밀번호 변경

바꾸고 싶은 항목만 입력하세요. 어느 쪽을 바꾸든 현재 비밀번호는 꼭 필요합니다. 비밀번호는 8자 이상이고 영문과 숫자를 모두 포함해야 합니다.
영문, 숫자, 점(.), 밑줄(_), 하이픈(-)만 사용, 3~64자. 아이디를 바꾸면 다시 로그인해야 합니다.

비밀번호를 잊었을 때

서버에서 환경 변수 ADMIN_RESET_PASSWORD=true 로 한 번 재시작하면 ADMIN_USERNAME / ADMIN_PASSWORD 값으로 초기화됩니다. 초기화 뒤에는 반드시 다시 false 로 되돌리고, 여기서 새 비밀번호로 바꿔주세요.
